Complete guide to integrating with Workly India platform

Getting Started
1. Generate API Key

First, generate your API key from the API Documentation page. Keep it secure and never expose it in client-side code.

2. Choose Your SDK

Select from JavaScript/TypeScript, Python, cURL, or Postman based on your technology stack.

3. Install & Configure

Install the SDK using your package manager and configure it with your API key.

Authentication

All API requests must include your API key in the X-Api-Key header:

X-Api-Key: YOUR_API_KEY

# Example with actual endpoint:
curl -H "X-Api-Key: YOUR_API_KEY" \
  https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-search
Security Best Practices:
Never commit API keys to version control
Use environment variables for storing keys
Rotate keys regularly
Use different keys for development and production
Implement proper access controls

Webhooks

Receive real-time notifications when events occur in your Workly India account.

Available Events:
job.application.created - When a new application is submitted
job.boost.activated - When a job boost is activated
Register Webhook:
POST https://jubwzelupbntbetpajqb.supabase.co/functions/v1/webhook-register
X-Api-Key: YOUR_API_KEY
Content-Type: application/json

{
  "url": "https://your-domain.com/webhook",
  "events": ["job.application.created", "job.boost.activated"],
  "description": "Production webhook endpoint"
}

Response:
{
  "success": true,
  "data": {
    "id": "webhook-id",
    "secret": "whsec_xxxxx",
    "url": "https://your-domain.com/webhook",
    "events": ["job.application.created"]
  }
}
Verify Signature:
// Node.js example
const crypto = require('crypto');

function verifyWebhookSignature(payload, signature, secret) {
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify(payload))
    .digest('hex');
  
  return signature === expectedSignature;
}

app.post('/webhook', (req, res) => {
  const signature = req.headers['x-webhook-signature'];
  const secret = process.env.WEBHOOK_SECRET;
  
  if (!verifyWebhookSignature(req.body, signature, secret)) {
    return res.status(401).json({ error: 'Invalid signature' });
  }
  
  // Process webhook...
  res.sendStatus(200);
});
Best Practices
Implement exponential backoff for rate limit errors
Cache responses when appropriate to reduce API calls
Use pagination for large datasets
Set appropriate timeouts for API requests
Log API errors for debugging and monitoring
Use webhooks for real-time updates instead of polling
Always verify webhook signatures to ensure authenticity
