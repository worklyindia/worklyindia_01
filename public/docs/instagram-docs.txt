Integrations
Use an Instagram Professional (Business or Creator) account. In the Instagram app turn on Settings → Messages → Allow access to messages.
Open AI Connect → Instagram in your account and connect it.
Open Developer Portal → Generate New Key. Store the wfh_ key only on your server.
Add your server URL under Developer Portal → Webhooks and subscribe to instagram.* events.
Send "platform":"instagram" in every request body.

Endpoint: POST https://jubwzelupbntbetpajqb.supabase.co/functions/v1/whatsapp-api

Header: x-api-key: wfh_YOUR_API_KEY

Body: {"platform":"instagram","action":"..."}

Meta login and permissions: Direct Instagram Login supports Professional accounts without requiring a linked Facebook Page. The Facebook Login connection path instead needs a linked Page. Direct-login permissions include instagram_business_basic, instagram_business_manage_messages and instagram_business_manage_comments.

When operating your own Meta app, development mode is for app roles and test accounts. Access for other businesses depends on Meta's App Review, permission access level and any required business verification. Connecting an account does not automatically approve permissions or bypass messaging policy.

All account names, IDs, API keys and media links in the examples are placeholders, not connected accounts. Replace them with values returned by your own API responses. Never send a real API key or access token to an AI assistant.

Your website's server (Node, PHP, Python…) calls the API. Your web page talks only to your server.
CRM, Zapier, Make, n8n: use an HTTP request step with the same URL, header and JSON.
Never put the API key in browser JavaScript or a mobile app.

Multiple Instagram accounts
Connect more from AI Connect → Instagram → Add account. Your developer API key accesses accounts connected to the same Workly user only; each Meta account has its own connection and access token. It cannot access another user's accounts.
Call list_accounts to get each account. Add "account" to any request with the account_id, the ig_user_id or the @username.
If only one is connected it is used automatically; with several, the request returns 400 until you pass "account". An unknown account returns 404.

Send messages & media
Standard automated replies are allowed within 24 hours of the customer's last message. This API does not expose a HUMAN_AGENT tag or an exemption for automated follow-ups. A permitted private reply to a comment is a separate flow; it does not grant unrestricted messaging.
to is the customer id from the inbox or webhook (not a phone number or username).
Text up to 1000 characters. Media must be a public HTTPS link: image, video, audio.
reply_to quotes a message. mark_read shows "Seen"; add "typing":true to show typing.

Posts & comments
list_posts lists your posts and reels; list_comments lists comments with replies.
reply_comment replies publicly under the comment.
private_reply sends a private message to the person who commented (once per comment, within 7 days).
After a private reply, wait for the customer to respond before sending follow-up messages; their response opens the normal 24-hour window. Instagram Live comment replies have a separate limit: reply while the broadcast is live. Meta enforces eligibility and may reject an expired or unsupported comment.

Incoming messages (webhooks)

Add a webhook in Developer Portal → Webhooks and select instagram.message.received, instagram.comment.received or instagram.*. Each POST has X-Webhook-Event and X-Webhook-Signature (HMAC-SHA256 hex of the raw body with your endpoint secret). Reply with HTTP 200 within 8 seconds.

Build your own Instagram inbox
Your server exposes 3 routes: chat list, messages, send.
Your page shows chats on the left and messages on the right, calling only your server.
The webhook saves new messages and refreshes the open chat in real time.
Action
Server (Node.js / Express)

Keeps the API key private.

Code example
// server.js — your own Instagram inbox backend (Express)
import express from "express";
const app = express();
app.use(express.json());

const API = "https://jubwzelupbntbetpajqb.supabase.co/functions/v1/whatsapp-api";
async function workly(body) {
  const res = await fetch(API, {
    method: "POST",
    headers: { "x-api-key": process.env.WORKLY_API_KEY, "Content-Type": "application/json" },
    body: JSON.stringify({ platform: "instagram", ...body }),
  });
  const data = await res.json();
  if (!data.success) throw Object.assign(new Error(data.error), { status: res.status });
  return data;
}

// 1. Left side: list of chats
app.get("/api/inbox", async (req, res) => {
  res.json(await workly({ action: "list_conversations", limit: 25, after: req.query.after }));
});

// 2. Open a chat: messages
app.get("/api/inbox/:id", async (req, res) => {
  res.json(await workly({ action: "get_messages", conversation_id: req.params.id, limit: 50 }));
});

// 3. Reply box
app.post("/api/inbox/send", async (req, res) => {
  const { to, text, reply_to } = req.body;
  await workly({ action: "mark_read", to });
  res.json(await workly({ action: "send_text", to, text, reply_to }));
});

app.listen(3000);

Inbox page (React)

Simple chat list + chat window.

Code example
// InboxPage.jsx — calls YOUR server only (never the API key in the browser)
import { useEffect, useState } from "react";

export default function InboxPage() {
  const [chats, setChats] = useState([]);
  const [active, setActive] = useState(null);
  const [messages, setMessages] = useState([]);
  const [text, setText] = useState("");

  useEffect(() => { fetch("/api/inbox").then(r => r.json()).then(d => setChats(d.conversations)); }, []);
  const open = async (c) => {
    setActive(c);
    const d = await fetch("/api/inbox/" + c.conversation_id).then(r => r.json());
    setMessages(d.messages.reverse());
  };
  const send = async () => {
    await fetch("/api/inbox/send", { method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ to: active.customer.id, text }) });
    setMessages(m => [...m, { message_id: Date.now(), text, direction: "outgoing" }]);
    setText("");
  };

  return (
    <div style={{ display: "flex" }}>
      <aside>{chats.map(c => <button key={c.conversation_id} onClick={() => open(c)}>
        {c.customer?.name} — {c.last_message?.text}</button>)}</aside>
      <main>
        {messages.map(m => <p key={m.message_id} align={m.direction === "outgoing" ? "right" : "left"}>{m.text}</p>)}
        {active && <><input value={text} onChange={e => setText(e.target.value)} /><button onClick={send}>Send</button></>}
      </main>
    </div>
  );
}

def workly(body):

Troubleshooting
400 — Invalid request
A field is missing or wrong (see details), or Meta rejected it (see meta_code).
401 — API key problem
Missing, invalid, inactive or expired x-api-key.
402 — Subscription inactive
Activate an API plan in Developer Portal.
404 — Account not connected
The account value does not match. Call list_accounts.
409 — Not connected
Connect Instagram on the AI Connect page, or reconnect if the token expired.
meta_code 10 / 551 — Permission or recipient restriction
Check the full Meta error message, app permissions, recipient availability and messaging window. These codes alone do not prove the 24-hour window expired.
meta_code 190 — Token expired
Reconnect Instagram on the AI Connect page.
meta_code 100 — Invalid parameter
Wrong to / conversation_id / comment_id, or the media URL is not public.
502 — Meta unavailable
Temporary outage. Retry after a short wait.
