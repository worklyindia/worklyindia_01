Direct API integration using fetch or axios

No NPM package installation required! Use standard HTTP libraries like fetch or axios to call the API directly.

Initialize your API configuration:

Get Job Details by ID

Fetch complete details for a specific job:

Copy
// Get job details by ID
const getJobDetails = async (jobId) => {
  const response = await fetch(`https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-search?job_id=${jobId}`, {
    method: 'GET',
    headers
  });

  const data = await response.json();
  
  if (data.success && data.data.length > 0) {
    const job = data.data[0];
    console.log('Job Title:', job.title);
    console.log('Company:', job.company_name);
    console.log('Location:', job.location);
    console.log('Salary:', `${job.salary_currency} ${job.salary_min} - ${job.salary_max}`);
    console.log('Skills:', job.skills.join(', '));
    console.log('Workly India:', job.remote_work);
    console.log('Applications:', job.application_count);
    return job;
  } else {
    console.error('Job not found');
    return null;
  }
};

// Usage
getJobDetails('123e4567-e89b-12d3-a456-426614174000');

Create Job Posting

Copy
// Post a new job
const createJob = async (jobData) => {
  const response = await fetch('https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-create', {
    method: 'POST',
    headers: {
      'X-Api-Key': API_KEY,

Error Handling

Handle API errors gracefully:

Copy
const apiCall = async () => {
  try {
    const response = await fetch('https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-search?search_query=developer', {
      headers: {
        'X-Api-Key': API_KEY,
        'Content-Type': 'application/json'
      }
    });

    if (!response.ok) {
      const error = await response.json();
      
      if (response.status === 429) {
        console.error('Rate limit exceeded');
        const retryAfter = response.headers.get('Retry-After');
        console.log('Retry after:', retryAfter, 'seconds');
      } else if (response.status === 401) {
        console.error('Invalid API key');
      } else {
        console.error('API Error:', error);
      }
      
      throw error;
    }

    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Request failed:', error);
    throw error;
  }
};
Using Axios (Alternative)

Install axios: npm install axios

Axios example:

Copy
import axios from 'axios';

const api = axios.create({
  baseURL: 'https://jubwzelupbntbetpajqb.supabase.co/functions/v1',
  headers: {
    'X-Api-Key': API_KEY,
    'Content-Type': 'application/json'
  }
});

// Search jobs
const searchJobs = async (query, location) => {
  try {
    const { data } = await api.get('/jobs-search', {
      params: { query, location, page: 1, limit: 20 }
    });
    return data;
  } catch (error) {
    if (error.response) {
      // Server responded with error
      console.error('API Error:', error.response.data);
      console.error('Status:', error.response.status);
    } else {
      // Network error
      console.error('Network Error:', error.message);
    }
    throw error;
  }
};

// Create job
const createJob = async (jobData) => {
  const { data } = await api.post('/jobs-create', jobData);
  return data;
};
TypeScript Support

Define types for better type safety:

Type definitions:

Copy
// types.ts
export interface Job {
  id: string;
  title: string;
  description: string;
  location: string;
  salary_min?: number;
  salary_max?: number;
  skills: string[];
  created_at: string;
}

export interface JobSearchParams {
  query?: string;
  location?: string;
  page?: number;
  limit?: number;
}

export interface ApiResponse<T> {
  success: boolean;
  data: T;
  message?: string;
}

// api.ts
const searchJobs = async (params: JobSearchParams): Promise<ApiResponse<Job[]>> => {
  const queryParams = new URLSearchParams(
    Object.entries(params).map(([k, v]) => [k, String(v)])
  );

  const response = await fetch(`https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-search?${queryParams}`, {
    headers: {
      'X-Api-Key': API_KEY,
      'Content-Type': 'application/json'
    }
  });

  return response.json();
};

Include your API key in the X-Api-Key header for all requests. Never expose your API key in client-side code.
Free tier allows 100 requests/day with 1 API key. Pro tier provides 10,000 requests/day with 2 API keys and priority support.
Paid actions (job posting, boosting, extension and interviews) are paid via Razorpay in the employer portal. Jobs created through the API are saved as drafts until payment is completed.
