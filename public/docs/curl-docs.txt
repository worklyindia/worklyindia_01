cURL Documentation

Direct API calls using cURL for testing and debugging

Search Jobs (GET)

Find jobs with search filters:

Copy
curl -X GET "https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-search?search_query=developer&location=mumbai&page=1&limit=20" \
  -H "X-Api-Key: your-api-key" \
  -H "Content-Type: application/json"

Create Job (POST)

Post a new job to the platform:

Copy
curl -X POST "https://jubwzelupbntbetpajqb.supabase.co/functions/v1/jobs-create" \
  -H "X-Api-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Senior Developer",
    "description": "Looking for experienced developer",
    "location": "Mumbai",
    "salary_min": 800000,
    "salary_max": 1200000,
    "salary_period": "yearly",
    "salary_currency": "INR",
    "skills": ["React", "Node.js", "MongoDB"]
  }'

Required Headers

Authorization

Bearer token with your API key. Required for all requests.

X-Api-Key: your-api-key

Content-Type

Specifies JSON format for request and response data.

Content-Type: application/json
Common Response Codes
200

Success - Request completed successfully

201

Created - Resource created successfully

400

Bad Request - Invalid parameters

401

Unauthorized - Invalid API key

429

Rate Limited - Too many requests

Testing Tips
•
Use -v flag for verbose output to see headers and debug info
•
Add -w "\n" to print a newline after response
•
Save responses to file with -o output.json
•
Use jq to format JSON output: curl ... | jq
•
Test webhook security by verifying signatures in your webhook handler

Common Pitfalls & Solutions

❌ Incorrect JSON escaping in shell

✅ Use single quotes around JSON data or escape double quotes properly

❌ Not handling special characters in URLs

✅ URL encode parameters or use --data-urlencode

❌ Missing Content-Type header for POST

✅ Always include -H 'Content-Type: application/json' for JSON data

Check the X-RateLimit-Remaining header in responses. When you get a 429 status code, wait for the time specified in the Retry-After header before making more requests.
Include your API key in the X-Api-Key header for all requests. Never expose your API key in client-side code.
Free tier allows 100 requests/day with 1 API key. Pro tier provides 10,000 requests/day with 2 API keys and priority support.
Paid actions (job posting, boosting, extension and interviews) are paid via Razorpay in the employer portal. Jobs created through the API are saved as drafts until payment is completed.
Boost packages increase your job's visibility. Package 1 is Standard (100 points/week), Package 2 is Premium (200 points/week), and Package 3 is Featured (300 points/week). The boost_level parameter (1-3) determines visibility priority.
If your wallet balance is insufficient, you'll receive a 402 Payment Required error. You'll need to add more points to your wallet before you can boost or extend jobs.
Use the -o flag: curl -o response.json 'URL' -H 'X-Api-Key: your-key'
Use -X POST -H 'Content-Type: application/json' -d '{"key":"value"}'
cURL is great for testing and debugging. For production, use a proper SDK or HTTP library in your programming language.
